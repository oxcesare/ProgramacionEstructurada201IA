Riesgo Tecnológico Detectado

Necesidad de Cambio: Vulnerabilidad y Obsolescencia

El Problema Central

QueryDSL ha entrado en un estado de "End of Life" (EOL) técnico. La falta de mantenimiento activo representa un riesgo crítico para la estabilidad y seguridad de los 87 módulos del proyecto.

"Depender de librerías sin soporte activo bloquea la actualización a futuras versiones de Spring Boot y Java."

Vulnerabilidades de Seguridad

Exposición a fallos detectados en dependencias transitivas que ya no reciben parches (CVEs sin resolver).

Falta de Soporte Oficial

El repositorio oficial no presenta actividad significativa de mantenimiento para las versiones más recientes de Spring Data.

Incompatibilidad con Java 17+

Conflictos recurrentes con el procesamiento de anotaciones (APT) y la generación de QClasses en entornos modernos.

Decisión Estratégica: Migrar a MongoDB Native Query API elimina la dependencia de terceros y asegura que el 100% de la capa de persistencia sea mantenida por el equipo de Spring / MongoDB.
